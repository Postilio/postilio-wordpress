# Postilio for WordPress

Sends the email of a WordPress site through [Postilio](https://postilio.eu), European transactional email, instead of
the server's own mail function. Every plug-in that calls `wp_mail()` (WooCommerce, Contact Form 7 and the like) sends
through Postilio without a change.

> Work in progress; not released yet.
